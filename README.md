# Moxxie 0.9.3 — Quatre nouveaux styles

**[Télécharger Moxxie pour Windows](https://github.com/AlvaroCatoiraP/Moxxie-downloads/releases/latest/download/Moxxie-Setup.exe)** · **[Manuel HTML](https://github.com/AlvaroCatoiraP/Moxxie-downloads/releases/latest/download/Moxxie-Documentation.html)** · **[Versions et empreintes](https://github.com/AlvaroCatoiraP/Moxxie-downloads/releases)**

- Prisme, Nébuleuse, Nexus et HUD intégrés, en plus d’Éclipse et Focus.
- Choix par profil dans **Réglages → Apparence**, avec aperçu et application immédiate.
- Un seul nom et un lancement unifié : **Moxxie**.
- Toutes les fonctions 0.9.1 conservées : mémoire avec provenance, calculs locaux vérifiés et contrôle des références.
- Suivi automatique des nouvelles réponses corrigé ; la remontée volontaire dans l’historique reste respectée.
- Consigne de vrais emojis Unicode, selon la fréquence choisie dans la personnalité.
- Chat, Bibliothèque, École, Université, profils, compagnons et dispositions Éclipse/Focus conservés.

Validation : 337 tests automatisés et 324 contrôles natifs de dimensions/navigation, autocontrôle de l’exécutable, installation, réinstallation, mise à jour avec redémarrage et désinstallation isolées réussis. Livres, personnalités et apparences de test conservés.

Windows 10/11 64 bits. Python inclus ; moteur local installé séparément. Aucun téléchargement ni changement automatique de modèle. Les mises à jour conservent les données dans leur dossier existant. Aucun profil personnel, livre privé ou identifiant n’est distribué ; le code de développement reste privé.

Les styles adaptent les maquettes au moteur natif. L’envoi de GIF dans le chat reste en conception. Les formulations du calculateur sont limitées ; la vérification des références ne garantit pas toutes les affirmations du modèle. Aucun second PC ni audit visuel exhaustif n’est revendiqué.

Télécharge l’installateur dans les fichiers de la Release ; les archives automatiques « Source code » ne sont pas le programme Windows. Les anciennes versions restent disponibles.
